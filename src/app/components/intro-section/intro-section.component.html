Intro

I'm a full stack software engineer who builds across the stack, from user-facing interfaces to backend services, automation, tooling, and infrastructure.

It is more than a static site: the background is a space simulation with a custom physics engine I built, hidden easter eggs, power-ups, and even a rocket-ship interaction for sending a message. I also added a dynamic GitHub component that pulls in my latest work directly from GitHub, so the portfolio stays current while giving visitors something interactive to explore.
